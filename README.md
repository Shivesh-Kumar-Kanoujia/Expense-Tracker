# Expense-Tracker
Personal Expense Tracker + Analyzer is a Flask-based web application developed using Python to help users record and manage their daily expenses efficiently. Users can add expense details such as date, category, and amount, which are stored in a CSV file using file handling techniques. The project uses Object-Oriented Programming (OOP) for better code structure and management through classes like Expense and ExpenseTracker. Pandas and NumPy are used for expense analysis, while Matplotlib generates graphical visualizations of spending patterns. The application provides insights such as total spending, average expenses, and category-wise analysis through a simple and user-friendly interface.
Features: (CRD)
1. You can add your expenses.
2. You can view your expenses.
3. You can delete your expenses
